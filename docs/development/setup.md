# Development Setup

## Requirements

The following tools are required:

- Python
- uv
- Git
- Docker Desktop

## Install Dependencies

Install the project dependencies using:

```bash
uv sync
```

## Run Tests

Run the test suite:

```bash
uv run pytest
```

## Run Linting

Run Ruff:

```bash
uv run ruff check .
```

## Start Docker Compose

Build and start the application:

```bash
docker compose up --build -d
```

Check the running services:

```bash
docker compose ps
```

The environment contains:

- `llmops-api` — FastAPI application
- `llmops-ollama` — Ollama LLM runtime

## Verify Ollama

Check available models:

```bash
docker compose exec ollama ollama list
```

The configured model should be available before sending requests to the API.

## Verify API

The API is available at:

`http://localhost:8000`

Swagger UI:

`http://localhost:8000/docs`

Health check:

```bash
curl http://localhost:8000/health
```

Expected response:

```json
{
  "status": "healthy",
  "version": "0.1.0"
}
```

## Test the Agent

Send a request to:

`POST /agent/chat`

Example request:

```json
{
  "conversation_id": "test",
  "message": "Hello"
}
```

The API should return a response generated by the configured local LLM.

## Stop Docker Compose

Stop the application:

```bash
docker compose down
```

The Ollama model volume is preserved when the containers are stopped.

## Quality Checks

Before committing changes, run:

```bash
uv run pytest
uv run ruff check .
docker compose config
```
